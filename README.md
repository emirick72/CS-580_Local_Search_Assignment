# Local Search Using Hill Climbing Algorithm

Note: For executing both parts of this assignment, the user must have Python, `numpy` and `matplotlib` installed on their machine.

------------------------------
## Part 1
Part 1 of the Local Search assignment shows the optimization of the Eggholder function with real parameters.

### How to execute:
Run this command to execute the code for `eggholder.py`:
`python eggholder.py`

------------------------------
## Part 2
Part 2 of the Local Search assignment shows the implementation of the Hill Climbing algorithm in order to find the solution to the N-Queens Problem.

### How to execute
Run this command to execute the code for `n_queens.py`:
`python n_queens.py`
